# Copy discipline and the AI-flavor blacklist

Copy is evidence-shaped speech. Every sentence must either carry a verifiable
fact, a real human voice, or a deliberate structural role (title, label,
caption, action). If a sentence only makes the work sound designed, delete it.

Classify additions before layout:

- `factual` — supplied by the user, recorded in project files, or verified from
  an allowed source; preserve the claim and source;
- `interpretive draft` — newly written title, synopsis, transition, or mood
  copy; mark it visibly in the control record and obtain approval before final
  delivery;
- `decorative/semantic` — non-factual words or graphics used for orientation,
  rhythm, category, or interaction; it must not impersonate metadata or proof.

When source content is thin, it is valid to draft bilingual titles, synopsis,
quotes, captions, chapter words, or explanations appropriate to the carrier.
Do not solve thin content by inventing credits, dates, coordinates, parameters,
statistics, product functions, or institutions.

## Voice rules

- Facts, numbers, quotes, and URLs stay verbatim-sourced. Never paraphrase a
  source quote into a smoother one.
- Prefer the plain declarative over the rhetorical. One idea per sentence.
- Specific over abstract: name the garment, the price, the year, the mechanism.
- Use the subject's real voice (docs, stories, user quotes) instead of
  inventing slogans about the subject.
- A contrast may exist only when the two sides are both true and both needed;
  never build a sentence whose purpose is the contrast itself.
- Factual inscriptions are encouraged, not banned: coordinates, readouts,
  dates, measurements, and source lines set as crafted small type are core
  project voice. The blacklist targets invented metadata and decorative
  microcopy — text with no source. Never delete a true value to look clean.
- Captions and callouts are a factual layer: name, role, sourced judgment.
  A caption that decorates instead of informing is a defect.
- Structural frames come from the source content. Comparisons, rankings,
  versus-pairings, and winner/loser emphasis may appear only when the source
  states them; never invent one for drama.
- At most one lyrical line per canvas. In a multi-level type system each
  level has a distinct job — orientation, definition, human stake,
  annotation, credit. Several poetic sentences in the same register are not
  levels; additional lines are plain, factual, or structural.
- User-supplied corrections are applied verbatim. Every sentence in a
  deliverable is either approved source copy or explicitly flagged as newly
  drafted, so the user can veto it.

## Blacklist — templated AI-flavor rhetoric

The following constructions are banned in all deliverable copy (title,
subtitle, body, captions, tags, closing), in any language. When a draft
contains one, rewrite it as a direct statement of what is true.

1. **Negation-contrast templates**
   - 「不是……而是……」 / 「不是……，是……」 / 「不是……，也不是……，而是……」
   - "not a X, but a Y" / "not just X — Y"
2. **False-suspense correction**
   - 「你以为……其实……」 / 「看起来……实际上……」 / "you'd think X — actually Y"
3. **Negation as selling point** — defining the subject by what it lacks
   (「没有信息流，也没有推荐算法」) unless the absence is a documented,
   source-backed product decision central to the proposition.
4. **Hollow parallelism** — antithetical couplets written for rhythm rather
   than meaning (「单品回答这是什么，关系回答为什么这样搭」 style
   ping-pong). If both halves are needed, write two plain sentences.
5. **Marketing abstractions** — 「让……发生」「为……赋能」「重新定义……」
   「开启……之旅」「……的答案」「把时间还给……」 and their English twins
   ("redefine", "unlock", "empower", "a journey of").
6. **Fake profundity closers** — a final line that gestures at meaning without
   stating any (「衣服是时间的刻度」 is allowed only when the whole set has
   earned it through specific evidence; when in doubt, end on a fact).
7. **Emoji or punctuation as personality** — emoji standing in for a voice the
   copy itself failed to establish; exclamation marks the source did not use.

## Sweep rule

Before delivery, grep the editable source for the patterns above (「不是」,
「而是」, 「你以为」, 「其实」, "not a", "not just", "redefine", "unlock").
Every hit must be rewritten or justified in `PROCESS.md` with its source.
