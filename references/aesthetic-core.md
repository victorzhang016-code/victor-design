# Aesthetic core

## 1. Discover the cause

Use the native structured question interface when callable; otherwise ask in
plain prose, grouping the questions so the user can answer in one reply. Ask
only what has
not already been established, then confirm a proposition before substantial
production. Establish:

- **human stake** — whose perception, choice, memory, effort, or risk matters;
- **subject tension** — what is held together, interrupted, lost, gained, or
  made visible;
- **unique soul** — the material, relation, contradiction, or memory that
  cannot be exchanged for a generic example;
- **audience task** — what must be understood, felt, or done at the actual
  viewing distance and context;
- **content truth** — required title, language, evidence, mechanism, identity,
  and refusal list.

When several directions are genuinely defensible, make up to three low-fidelity
previews with real copy lengths and output geometry. Do not ask for a style
label when the subject already suggests a direction.

## 2. Translate meaning into form

Write a felt brief:

> Before understanding **[content]**, the audience feels **[first sensation]**.
> During reading or use, sustain **[tension/rhythm]**. Afterwards retain
> **[residue]**.

Then make a concise form-cause table for every major choice:

| Choice | Subject cause | Viewer effect | Why this carrier |
| --- | --- | --- | --- |
| field / boundary | | | |
| scale / crop | | | |
| type voice | | | |
| color event | | | |
| image or material relation | | | |

If a row cannot be completed, the move is decoration. Remove it or return to
the subject. The reverse failure is equally disqualifying: if every row is
empty, the page is not designed. Restraint is a choice among crafted
elements, not their absence — see `workflow/density-and-care.md` for the
positive layer model and density calibration.

## 3. Compose an authored world

Build a field before placing modules. Let one dominant relation interrupt it,
then place text, evidence, and quiet space around the same pressure. A title
may anchor, interrupt, or enter the world; it is not a default header card.

Compose in layers — treated field, dominant event, evidence, factual
inscription, furniture, and at most one material node — using
`workflow/density-and-care.md`. Quiet space belongs between crafted layers;
it is not a substitute for them.

Use scale, crop, whitespace, material, and color as consequences of the
subject. Make asymmetry inevitable rather than random. Show supporting evidence
only when it changes understanding; retain body copy when trust needs it.

### Material-relationship discovery

Inspect eligible source material for a visual relationship that makes the idea
felt rather than merely captioned:

- a physical carrier receives a living digital memory or interface;
- an analogue and contemporary state form a temporal bridge;
- an inserted image inherits its host’s perspective, light, contour, or scale;
- paired elements share a transform, crop, clip, or shadow because they are one
  material event.

Name the relation, its host/pair, shared rule, and revealed meaning before
composition. Use only material relations discovered from the eligible source
pool; an example must never become a reusable motif or an asset recipe. Do not
replace material contact with a line joining separate pictures.

## 4. Type, color, and refusal

Choose type by voice, language support, reading distance, and role. Test the
actual title, proposition, and necessary body copy before layout. Declare a
small fixed type ladder before composing — a handful of steps with assigned
roles, used identically on every page or screen; per-page sizes invented on
the fly are a defect. Character
comes first from hierarchy, rhythm, crop, and alignment; a typeface cannot make
an unrelated subject feel designed.

Give color one stable emotional or semantic role. Use material only where it
changes time, pressure, trust, or tactility. Reject fake technical microcopy,
decorative metadata, default accent bars, gratuitous containers, and generic
AI spectacle when they hide a missing causal decision. These are red flags, not
a visual identity.

## 5. Review in the right order

Ask first whether the work could only belong to this subject. Then test first
attention, hierarchy, spacing, reading distance, content truth, and task
clarity. Deterministic checks may find defects; they cannot certify taste.

### Retained external mechanisms

- Preserve copy integrity and factual-source checks from Taste.
- Use Impeccable’s authored critique → deterministic audit → reconciliation.
- Use low-fidelity direction previews only under genuine ambiguity.
- Use subject maps, quiet zones, localized tint, and thumbnail checks only when
  type overlays imagery or screenshots.
